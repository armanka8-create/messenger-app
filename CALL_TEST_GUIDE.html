📹 Video Call Test Guide

⚠️ MOST COMMON MISTAKE:

You MUST click on the user's name in the sidebar BEFORE clicking the call button!

The call buttons won't work if no chat is selected.

Step 1: Setup Two Browser Windows

Window 1 (Regular Chrome):

  • Go to: http://localhost:3000
  • Login as: alice / test123

Window 2 (Incognito - Press Cmd+Shift+N):

  • Go to: http://localhost:3000
  • Login as: bob / test123

✅ Both users should now be logged in

Step 2: Select the User in Sidebar (IMPORTANT!)

In Window 1 (Alice):

  1. Look at the LEFT sidebar
  2. You should see "Bob Jones" with a gray dot (offline) or green dot (online)
  3. CLICK on "Bob Jones"
  4. The name should HIGHLIGHT in blue/purple
  5. The right side should show the chat area with:
    • "Bob Jones" at the top
    • Two buttons: 📞 and 📹
    • Message input box at bottom

✅ User selected = Chat area visible on right

❌ No user selected = Just empty screen or "Select a chat to start messaging"

Step 3: Start the Video Call

In Window 1 (Alice's window):

  1. Make sure Bob is selected (highlighted in sidebar)
  2. Click the 📹 button (top right of chat area)
  3. Chrome will ask: "localhost wants to use your Camera and Microphone"
  4. Click "Allow"
  5. You should see:
    • Black overlay covering the screen
    • Text: "Call with Bob Jones"
    • Your own video (small box, bottom right corner)
    • "End Call" button

✅ You should see your own face in the small video box

Step 4: Answer the Call

In Window 2 (Bob's incognito window):

  1. You should see a popup overlay:
    • "📞 Incoming video call"
    • "alice"
    • "Answer" button (green)
    • "Reject" button (red)
  2. Click "Answer"
  3. Chrome will ask: "localhost wants to use your Camera and Microphone"
  4. Click "Allow"
  5. You should now see:
    • Alice's video (large, main area)
    • Your own video (small box, bottom right)
    • "End Call" button

✅ Both windows should now show live video!

🐛 If Nothing Happens When You Click 📹:

Checklist:

  1. Did you select a user?
    → Click on "Bob Jones" in the LEFT sidebar first
  2. Is the chat area visible?
    → You should see the chat interface on the right
  3. Are the buttons visible?
    → 📞 and 📹 buttons should be at top right
  4. Check the browser console:
    → Press F12
    → Click "Console" tab
    → Click the 📹 button again
    → Look for emoji logs like "🎥 Starting call..."
    → Or look for RED error messages

🔍 Debug Mode (Console Check)

Open Console (F12) and try the call:

You should see these logs if it's working:

  • 🎥 Starting call: video to user: Bob Jones
  • 🎤 Requesting media access...
  • ✅ Got local stream: ['audio', 'video']
  • ✅ Set local video element
  • ➕ Added track: audio
  • ➕ Added track: video
  • 📤 Sending call offer to: 2
  • ✅ Call initiated!

In Bob's window you should see:

  • 📞 Incoming call from: alice type: video

⚠️ Common Issues:

  • "NotAllowedError" → You blocked camera/microphone permissions
    Fix: Click 🔒 icon in address bar → Set Camera/Mic to "Allow" → Refresh
  • "NotFoundError" → No camera detected
    Fix: Check if your Mac has a camera, try restarting Chrome
  • "NotReadableError" → Camera in use by another app
    Fix: Close Zoom, FaceTime, Skype, etc. and try again
  • No logs at all → Button click not working
    Fix: Make sure you clicked on user in sidebar first!

✅ Success Looks Like:

  • Alice sees: Her own video (small) + waiting for Bob
  • Bob sees: Incoming call popup
  • Bob clicks Answer
  • Both see: Each other's video live!
  • Both can click "End Call" to disconnect

Still having issues? Check the console (F12) for error messages and report them back.
